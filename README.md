# AI-Driven Write

**AI 에이전트 협업 글쓰기 시스템** — Claude Code의 멀티 에이전트를 활용한 콘텐츠 제작 파이프라인

> 소프트웨어 개발용 PDCA 에이전트 팀을 **글쓰기 편집국**으로 리매핑한 실험 프로젝트입니다.

---

## 핵심 아이디어

소프트웨어 개발에서 코드 품질을 높이기 위해 쓰는 **PDCA(Plan-Do-Check-Act) 사이클**과 **전문가 에이전트 팀** 구조를, 글쓰기에 그대로 적용하면 어떨까?

- 코드 리뷰어 → **교열팀장**
- 아키텍트 → **보도국장**
- QA 엔지니어 → **편집자**
- 개발자 → **기자, 카피라이터, PD**

각 에이전트에게 10년+ 경력의 전문가 페르소나를 부여하고, 실제 언론사 편집국처럼 협업합니다.

---

## 방법론: Writing PDCA

### 에이전트 팀 구성

| 역할 | 페르소나 | 담당 |
|------|---------|------|
| **보도국장/디렉터** | 10년+ 언론사 보도국장 | 최종 방향 판단, 톤 결정, 게재 여부 |
| **시니어 기자** | 10년+ 탐사보도 기자 | 팩트 검증, 논점 구성, 취재 관점 |
| **편집자** | 10년+ 언론사 편집장 | 구조, 논리 흐름, 가독성, 독자 관점 |
| **교열팀장** | 10년+ 교열 전문가 | 문법, 맞춤법, 문체 일관성, 팩트 오류 |
| **카피라이터** | 10년+ 광고 카피라이터 | 후킹, 임팩트, 톤앤매너 |
| **PD/프로듀서** | 10년+ 시사다큐 PD | 스토리텔링, 기승전결, 감정선 |
| **헤드라인 디렉터** | 음악 평론가 출신 카피라이터 | 제목과 요약의 심도+임팩트 |
| **IT 번역 전문가** | Silicon Valley 10년+ 한국계 테크 라이터 | 영문 로컬라이제이션 |

### 워크플로우

```
Plan (기획)     작성팀 4인이 병렬로 방향/제목 제안
    ↓
Design (설계)   글의 구조(개요) 확정, 섹션별 논점 배치
    ↓
Do (집필)       3가지 버전 동시 작성
                  A안: 유머러스한 톤 (카피라이터)
                  B안: 진지한 울림 (기자)
                  C안: 팩트 중심 (PD)
    ↓
Check (검수)    교열팀 + 편집팀 병렬 검수
    ↓
Polish          헤드라인 디렉터가 제목/요약 다듬기
    ↓
Act (판단)      디렉터 최종 추천 → 사람이 최종 선택
    ↓
Localize        (선택) 영문 번역/로컬라이제이션
```

### 왜 3가지 버전을 동시에 쓰는가?

같은 소재라도 **톤에 따라 전혀 다른 글**이 됩니다. 유머, 진지함, 팩트 중심 — 세 가지 관점을 동시에 보면 최적의 방향을 찾을 수 있습니다. AI이기 때문에 가능한 접근입니다.

## 강의 콘텐츠 팀

글쓰기 팀과 별도로, **유튜브 강의 제작**에 특화된 에이전트 팀도 운영합니다.

| 역할 | 담당 |
|------|------|
| **1타 강사** | 강의안(스크립트) 작성, 데모 시나리오 |
| **강의 기획자** | 커리큘럼 설계, 난이도 곡선, 청중 분석 |
| **치프 편집자** | 영상 편집 가이드, 컷 리스트, 자막 포인트 |
| **IT 번역 전문가** | TTS용 영문 스크립트 로컬라이제이션 |

**워크플로우**: 기획 → 집필 → 검수 → 편집 가이드 → 최종 확인 → (영문 번역)

```

  drafts/           # 글 작업 폴더 (A안/B안/C안)
  finals/            # 최종 원고
  lectures/          # 강의 작업 폴더
  final-lectures/    # 강의 최종 산출물
  references/        # 참고 자료
CLAUDE.md            # 에이전트 팀 설정 & 워크플로우 정의
```

## 이런 분에게 유용합니다

- AI로 글을 쓰는데, "한 번에 뽑기"보다 **체계적인 프로세스**가 필요한 분
- 콘텐츠 품질을 높이기 위해 **여러 관점의 초안 비교**를 원하는 분
- Claude Code의 멀티 에이전트를 **비개발 분야**에 활용하고 싶은 분
- 유튜브 강의 제작을 **기획부터 편집 가이드까지** 자동화하고 싶은 분
