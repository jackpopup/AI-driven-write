## 2. 제품 상세

### bkit (Bkamp Vibecoding Kit) — Creation Engine
- Anthropic Claude Code 기반 AI 네이티브 개발 프레임워크
- PDCA(Plan-Design-Do-Check-Act) 방법론 자동화
- 3단계 레벨 시스템: Starter(정적 웹) → Dynamic(풀스택) → Enterprise(대규모)
- Zero Script QA: 별도 테스트 코드 없이 실시간 품질 검증
- Pro-Dev Flow Guide: 자연어를 전문 개발자 프로세스로 변환
- 시뮬레이션 기준: 10인 팀 프로젝트 → 1인 바이브코더로 가능, 연간 10억원+ 절감
- MVP 개발: 3-6개월 → 1주-1개월, 단순 기능: 수일 → 2-4시간
- 공식 사이트: bkit.ai

### bkend — Infrastructure Engine
- AI 네이티브 BaaS(Backend as a Service)
- 자연어로 3분 만에 DB, API, 배포 완료
- Zero DevOps Required
- MCP(Model Context Protocol) 통합
- 서버리스 백엔드 인프라
- 공식 사이트: bkend.ai

### bkamp — Scaling Engine
- AI 바이버들의 놀이터 (커뮤니티 플랫폼)
- 3가지 콘텐츠: Showcases(프로젝트 전시), Recipes(검증된 워크플로우), Riddles(실전 문제 협업)
- 8개국 언어 지원 (한/영/일/중/독/프/스/이)
- 공식 사이트: bkamp.ai

## 6. 현재 초안의 구조적 문제 (B2C→B2B 전환 어색함)

### 문제점
- 섹션 1-2: B2C 제품(bkit, bkend, bkamp) 소개 — 개인 바이브코더 대상
- 섹션 3: 갑자기 B2B 엔터프라이즈 컨설팅(7-Step Standard Process) 등장
- 연결 고리 없이 B2C→B2B로 점프하여 어색

### 7-Step Standard Process (현재 초안)
1. Data Onboarding — RAG System 구축
2. AI Secretary — 챗 인터페이스 제공
3. Docs & Specs — Context Engineering 문서 문화
4. Tech Sharing — Agent Registry
5. Vibe Coding — No-Code/Low-Code 개발
6. Internal App Store — 서비스 배포/재사용
7. Visual Monitoring — 토큰 사용량 거버넌스

### 해결 방향 (제안)
- 3 Engines를 "플랫폼"으로, 7-Step을 "엔터프라이즈 서비스"로 재포지셔닝
- B2C(개인 바이브코더) → B2B(기업 전체 AI 전환)로의 자연스러운 확장 논리 추가
- "개인이 검증한 도구 → 조직 전체에 이식" 서사 구축

## 9. 원본 초안

[PRESS KIT] 팝업스튜디오 (POPUP STUDIO) 기업 소개서

"글로벌 바이브코더를 위한 개발 인프라와 커뮤니티를 만드는 팝업스튜디오(POPUP STUDIO PTE. LTD.)"

1. 회사 개요 및 비전

팝업스튜디오는 싱가포르에 본사를 둔 국외창업기업으로, 글로벌 바이브코더를 위한 개발 인프라와 커뮤니티를 만들어 가고 있습니다.

우리는 AI 도입 이후 시장이 대화만 하는 그룹(Chatters)과 완결된 결과를 만드는 그룹(Builders)으로 갈라지는 'AI 대분기(Great Bifurcation)' 현상에 주목합니다. 대부분의 조직이 단순 챗봇 문답에 머무는 동안, 팝업스튜디오는 "단 한 명도 도태되지 않는(NO ONE LEFT BEHIND), 모두가 빌더가 되는 세상"을 비전으로 삼아 구성원 모두가 스스로 혁신할 수 있는 환경을 구축합니다.

2. 핵심 서비스: 3대 엔진 (3 Engines)

팝업스튜디오는 기업이 겪는 기술 격차, 성과 부재, 심리적 불안감을 해결하기 위해 최적화된 3가지 엔진을 제공합니다.

(1) bkit (Creation Engine) - 스킬 격차 해소, Context Engineering 자동화, PDCA 사이클

(2) bkend (Infrastructure Engine) - 실행 격차 극복, Zero DevOps, MongoDB 기반 확장성

(3) bkamp (Scaling Engine) - 조직의 심리적 불안(FOMO) 해결, 사내 에이전트 자산화

3. 핵심 수익 모델: 7-Step Standard Process

위 3가지 서비스에서 축적된 노하우를 바탕으로 단순한 툴을 넘어 "실패하지 않는 AI 조직"을 만들기 위해 7단계의 표준 프로세스(OS)를 이식합니다.
