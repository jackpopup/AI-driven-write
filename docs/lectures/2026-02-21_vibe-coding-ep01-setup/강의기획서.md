## 학습 목표 (4가지)

이 영상을 끝까지 따라하면 시청자가 얻어가는 것:

1. **개발 용어 첫인상** — 개발 용어(언어, 폴더, 터미널, 서버, GitHub)가 대화에 나와도 겁먹지 않을 정도로 감을 잡는다
2. **터미널 첫 경험** — 검은 화면(터미널)을 열어보고, 명령어를 복사-붙여넣기 해서 실행하는 경험을 한다
3. **AI 프롬프팅 감잡기** — AI에게 대충 시키는 것과 구체적으로 시키는 것의 차이를 체감한다
4. **첫 결과물 목격** — AI가 코드를 생성해서 웹페이지가 뜨는 과정을 직접 목격한다 (완벽히 이해하지 않아도 OK)
