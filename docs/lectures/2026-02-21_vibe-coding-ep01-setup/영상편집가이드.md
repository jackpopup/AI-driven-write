# 바이브 코딩 1편 — 영상 편집 가이드

> **제목**: "까만 화면 쫄지 마세요! 설치부터 첫 웹사이트까지"
>
> **러닝타임**: 약 20분
> **편집 원칙**: 기본은 PPT 슬라이드 전환 + 화면 녹화. 특수 편집은 **딱 3곳**만.

---

## 편집 기본 원칙

### PPT 기반 편집 (전 섹션 공통)
- 스크립트의 `[화면]` 태그에 적힌 PPT 페이지 번호를 참고하여 해당 슬라이드를 삽입
- 슬라이드 전환: **기본 컷** 또는 **페이드** (0.3초)
- 코드블록(``` 안의 내용)은 PPT 슬라이드로 미리 제작하여 삽입
- 설치/실습 장면은 화면 녹화 원본 사용, 설치 과정은 **2배속** 처리
- 자막은 스크립트의 `[자막]` 태그 내용을 화면 하단에 표시 (흰색 글자, 반투명 검정 배경)

### BGM 가이드 (전체)
- **섹션 1~2** (인트로~바이브코딩): 밝고 활기찬 톤, 110~120 BPM
- **섹션 3~5** (개념~프롬프팅): 차분한 설명 톤, 80~90 BPM
- **섹션 6** (라이브 데모): 빌드업 → 클라이맥스, 120 BPM
- **섹션 7** (정리): 차분한 마무리, 80 BPM → 페이드아웃
- BGM은 전체 1~2곡으로 통일 (섹션마다 바꾸지 않음, 볼륨 조절로 분위기 전환)

### 효과음 (전체)
- **"딩!"**: 체크포인트 성공 시 (node --version, python --version, claude --version 등) — 총 3~4회
- **경고음**: "Add Python to PATH" 강조 시 1회
- 그 외 효과음은 사용하지 않음 (과하면 산만해짐)

## 특수 편집 3곳 (애니메이션/모션그래픽)

> 아래 3곳만 PPT가 아닌 특수 편집을 적용합니다. 나머지는 전부 PPT + 화면 녹화.

---

### 특수 편집 #1: 인트로 웹사이트 리빌 [0:00~0:15]

**목적**: 시청자 후킹. 3초 안에 "이 영상 볼 가치 있다"를 각인

**편집 내용**:
- 완성된 포트폴리오 웹사이트가 브라우저에서 열려있는 장면
- **글로우 이펙트** (약한 파란색) + 천천히 스크롤 (3초)
- 스크롤 끝에 **"와!" 효과음** + 짧은 라이트 플래시
- 텍스트 오버레이: "20분 뒤, AI가 만든 웹사이트가 여러분 화면에 뜹니다" (임팩트 폰트, 페이드인)

**소요 시간**: 약 15초
**참고**: 이 웹사이트는 섹션 6 라이브 데모에서 실제로 만드는 결과물과 동일해야 함

---

### 특수 편집 #2: "Add Python to PATH" 경고 강조 [약 9:30]

**목적**: 실습 실패 방지. 이걸 놓치면 Python 재설치해야 하므로 최대한 강조

**편집 내용**:
- 설치 화면 녹화 중, "Add Python to PATH" 체크박스 지점에서:
  - **화면 멈춤** (3초)
  - 체크박스 위에 **빨간 동그라미 + 화살표** 그래픽 오버레이
  - **경고 효과음** 1회 (비상음 아닌 주의음)
  - 체크박스가 체크되는 **클릭 애니메이션**
- 텍스트 오버레이: "반드시 체크!!!" (빨간 배경, 흰색 큰 글자)

**소요 시간**: 약 5초 (멈춤 포함)
**참고**: 이 부분이 1편에서 시청자가 가장 많이 실패하는 지점

---

### 특수 편집 #3: 라이브 데모 클라이맥스 — 웹사이트 렌더링 [약 17:00]

**목적**: 영상의 감정 최정점. "와, 진짜 됐다!"를 극대화

**편집 내용**:
- AI가 코드 생성을 완료하고, 브라우저에서 웹사이트가 처음 렌더링되는 순간:
  - **슬로우모션** (0.5배속, 약 3초간)
  - BGM 전환: 빌드업 BGM → **감성 BGM** (부드러운 신스/스트링)으로 순간 전환
  - **"와!" 효과음** + 살짝 **글로우 이펙트**
  - 웹사이트로 **줌인** (천천히 가까워지는 카메라 효과)
- 이후 텍스트 오버레이: "여러분의 첫 번째 웹사이트가 탄생했습니다!" (감성적 폰트, 페이드인)

**소요 시간**: 약 8초 (슬로우모션 포함)
**참고**: 인트로(#1)에서 보여준 것과 같은 웹사이트가 실제로 만들어지는 과정이라는 연결감이 중요
