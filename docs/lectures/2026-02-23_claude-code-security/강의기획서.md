## 3. 학습 목표

이 영상을 본 후 시청자가 할 수 있어야 하는 것:

1. Claude Code Security가 기존 SAST 도구와 어떻게 다른지 **설명**할 수 있다
2. `/security-review` 명령어를 자신의 프로젝트에서 **직접 실행**할 수 있다
3. `.claude/commands/security-review.md`를 작성하여 **조직 맞춤 보안 규칙을 설정**할 수 있다
4. GitHub Actions에 보안 리뷰 워크플로우를 **구성**할 수 있다
5. 플랜별 기능 차이를 이해하고 자신의 상황에 맞는 **도입 전략을 판단**할 수 있다

## 6. 비유/화법 아이디어 (1타 강사 제안)

### 핵심 비유 3개

1. **"맞춤법 검사기 vs 편집장"**
   - 기존 SAST = 맞춤법 검사기 (오탈자는 잡지만 논리 오류는 못 잡음)
   - Claude Code Security = 편집장 (처음부터 끝까지 읽고 흐름상 문제를 잡아냄)

2. **"CCTV vs 탐정"**
   - CCTV = 패턴 매칭 (빨간 옷 입은 사람이 지나갔다)
   - 탐정 = AI 추론 (왜 이 시간에 여기를 지나갔는지 추론)

3. **"보안 전문가 채용 vs 구독"**
   - 시니어 보안 엔지니어 연봉 1억+ vs Claude PR당 50센트
   - "커피 한 잔 값도 안 되는 비용으로 24/365 보안 리뷰"

### 화법 패턴

- **"솔직히 말씀드리면"** 패턴 (신뢰 구축) → 한계를 먼저 인정하고 강점 부각
- **"여러분 회사에서..."** 패턴 (공감 유도) → 보안 리뷰 안 하는 현실 공감
- **"이건 제가 직접 해봐서 아는 건데"** 패턴 (경험 기반 설득)

## 11. 주의 및 보완 사항

| 항목 | 내용 |
|------|------|
| PPT 배포 | 슬라이드 자체가 배포 자료이므로 정보 밀도 적절히 유지. 발화문과 겹치지 않는 보충 정보 포함 |
| 플랜 접근성 | 현재 어떤 플랜에서 쓸 수 있는지 영상 초반에 명확히 안내 |

| 부속 자료 | `.yml` 파일, 커스텀 규칙 템플릿 등을 PPT 마지막 부록 슬라이드에 포함 |
