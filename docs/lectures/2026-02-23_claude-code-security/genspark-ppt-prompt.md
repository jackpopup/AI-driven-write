async function applyCoupon(orderId, couponCode) {
  const coupon = await db.findCoupon(couponCode);
  if (!coupon || coupon.expired) {
    throw new Error('Invalid coupon');
  }
  // ⚠️ 중복 적용 체크 없음!
  const order = await db.getOrder(orderId);
  order.discount += coupon.discountAmount;
  await order.save();
}
```

```
ESLint: PASS ✓  |  SonarQube: PASS ✓

동일 쿠폰의 중복 적용을 방지하는
로직이 없습니다.

공격자가 applyCoupon()을 반복
호출하여 무한 할인을 받을 수
있습니다.

수정 제안:
주문별 적용된 쿠폰 목록을 확인하고

**코드 블록 (VS Code 다크 테마, JetBrains Mono 17pt)**

핵심 3줄을 오렌지 하이라이트, 나머지는 투명도 60%

```yaml
name: Claude Security Review
on:
  pull_request:                          # ← 1. PR 트리거
    types: [opened, synchronize]

jobs:
  security-review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: anthropic/claude-code-action  # ← 2. Claude 호출
        with:
          command: /security-review          # ← 3. 명령어 지정
        env:
          CLAUDE_API_KEY: ${{ secrets.CLAUDE_API_KEY }}
```
