- **나레이션 (완료)**: 축하합니다! 환경 설정 3개 전부 완료! 여러분 컴퓨터에 AI가 들어왔어요.
- **자막**: 핵심: "Add Python to PATH" — 반드시 체크!!! / npm = 개발자용 앱스토어 (Node.js에 포함)

- **나레이션 (3원칙)**: 3원칙만 기억하세요. 원칙 1, 맥락을 제공하라. 원칙 2, 구체적으로 요청하라. "이쁘게 해줘" 말고 "배경색은 파란색, 글자 크기는 18px"로요. 원칙 3, 단계별로 지시하라. 한 번에 열 가지 말고 하나씩요.
- **나레이션 (BAD vs GOOD)**: 나쁜 프롬프트: "웹사이트 만들어줘." 좋은 프롬프트: "기자 포트폴리오 사이트. 배경은 #E0F7FA, 본문 18px로 해줘."
- **나레이션 (4요소 공식)**: 프롬프트 4요소 공식! 역할 — "프론트엔드 개발자로서". 맥락 — "기자용 포트폴리오". 요청 — "원페이지 웹사이트를 만들어줘". 제약 — "단일 파일로". 이 네 가지를 조합하면 AI가 정확하게 알아듣습니다.
- **자막**: AI 3원칙: 맥락 제공 + 구체적 요청 + 단계별 지시 / 프롬프트 4요소: 역할 + 맥락 + 요청 + 제약
