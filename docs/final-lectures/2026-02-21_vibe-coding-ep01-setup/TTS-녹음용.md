Python은 데이터 분석이랑 AI 쪽 전문가입니다. JavaScript는 웹 브라우저의 주인이죠. 오늘 우리는 웹사이트를 만들 거니까 JavaScript를 쓸 겁니다.

두 번째, 폴더와 파일. 폴더가 뭐냐면, 하나의 프로젝트 단위입니다. 그 안에 index html은 웹사이트의 뼈대, style css는 디자인, script js는 동작을 담당합니다. 이름만 알아두시면 됩니다. 외울 필요 없습니다.

세 번째, 터미널. 여러분이 제일 무서워하는 그 까만 화면이죠. 근데요, 이거 카카오톡 채팅창입니다. 진짜로요. 터미널에서는 컴퓨터한테 메시지를 보내는 겁니다. 까만 화면이 무서워 보이지만, 그냥 카톡 입력칸이라고 생각하십시오. 잘못 쳐도 컴퓨터 안 망가집니다.

네 번째, 웹의 구조. 레스토랑으로 비유해보겠습니다. 프론트엔드가 홀입니다. 손님이 보는 화면이죠. 백엔드가 주방입니다. 데이터를 처리하고 요리하는 곳이죠. 오늘은 홀만 만들 겁니다.

다섯 번째, GitHub. 이건 코드의 구글 드라이브라고 생각하시면 됩니다. 클라우드 백업이 되고, 타임머신처럼 과거 시점으로 되돌리기가 가능합니다. 실수로 코드를 다 망쳐도 어제 버전으로 바로 되돌릴 수 있습니다.

자, 다섯 가지 개념 다 끝났습니다! 정리하면, 컴퓨터 언어는 외국어, 폴더는 프로젝트 단위, 터미널은 카톡 채팅, 웹은 레스토랑, GitHub는 구글 드라이브. 이제 이 개념들을 직접 써먹을 차례입니다!

자, 실습 시간입니다. 환경 설정을 하나하나 따라할 건데, 오늘은 터미널 개념을 확실히 익히기 위해서 까만 화면에서만 작업합니다. 처음엔 낯설 수 있는데, 두세 번 해보시면 금방 익숙해집니다.

먼저 터미널을 열어보겠습니다. Windows 분은 잠시 후에 설치할 Git Bash를 쓸 겁니다. Mac 분은 Command + Space 누르고 Terminal이라고 치면 됩니다. 지금은 일단 따라오세요. 참고로 이 발표문은 영상 설명과 고정 댓글로 링크를 해놨으니 거기서 복사 붙여 넣기 하시면 됩니다.

첫 번째, Node.js를 설치합니다. AI 코딩 도구를 돌리려면 아까 말한 컴퓨터 언어가 필요합니다. Node.js가 바로 그 언어인데, 웹 서비스를 만드는 데 특화되어 있습니다. node.org에 들어가서 반드시 왼쪽 LTS 버전을 클릭해주세요. 설치 끝나면 터미널 창을 닫고 새로 열어주세요. 새로 설치한 프로그램은 터미널을 다시 켜야 반영이 됩니다. node --version, npm --version 치고 숫자가 나오면 성공입니다!

두 번째, Python을 설치합니다. Python은 데이터를 정리하거나, 자동 프로그램을 만드는데 많이 씁니다. python.org에서 다운로드하시고요, 여기서 아주 중요한 거! Add Python to PATH 체크박스를 반드시 체크해주세요! 이거 안 하면 나중에 Python을 설치했는데 컴퓨터가 못 찾는 황당한 상황이 벌어집니다.

git-scm.com에서 Git for Windows를 다운로드하세요. 설치 옵션은 전부 기본값으로 Next만 누르시면 됩니다. 시작 메뉴에서 Git Bash를 열어서 달러 표시가 뜨면 성공입니다! 이제부터 이 터미널을 씁니다.
