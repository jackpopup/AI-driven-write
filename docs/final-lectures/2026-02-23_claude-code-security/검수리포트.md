# 검수 리포트: Claude Code Security 해설 영상

## 총평

전체적으로 완성도가 높은 강의 스크립트입니다. 기획서에서 설정한 학습 목표, 난이도 곡선, 비유/임팩트 포인트가 스크립트에 충실하게 반영되어 있으며, 발화문의 톤과 흐름이 자연스럽습니다. 특히 "CCTV vs 탐정", "맞춤법 검사기 vs 편집장" 비유의 배치와 전개가 효과적이고, 기술 개념을 비전문가도 이해할 수 있는 수준으로 풀어내고 있습니다.

다만 몇 가지 구조적 보완이 필요합니다. 가장 주요한 이슈는 (1) 기획서에서 제시한 비유의 순서가 스크립트에서 뒤바뀌어 있는 점, (2) 일부 섹션의 발화문 분량이 배정 시간 대비 초과하는 점, (3) PPT 프롬프트와 스크립트 간 슬라이드 수 차이에서 발생하는 정합성 문제입니다. 이들은 모두 교정 가능한 수준이며, 전체 구조를 흔들 정도의 문제는 아닙니다.

## 상세 검수 내용

### 1. 기획서 대비 정합성

**비유 순서 역전 문제**

기획서 커리큘럼 구조(섹션 3, 2:30~5:00)에서는 "기존 SAST vs AI" 비교가 "규칙 매칭 vs 코드 이해"라는 큰 프레임 안에서 전개되고, "500개 취약점" 실적이 이 섹션 안에 배치되어 있습니다. 스크립트에서도 이 구조를 따르고 있으나, 비유의 등장 순서가 달라졌습니다.

- 기획서 임팩트 포인트 #2에서는 "맞춤법 검사기 vs 편집장"이 먼저 등장하고 그 뒤에 비즈니스 로직 결함 도식이 이어지는 흐름입니다.
- 스크립트에서는 슬라이드 4에서 "CCTV vs 탐정"(문제 제기 섹션 말미)을 먼저 사용한 뒤, 슬라이드 5에서 다시 "CCTV vs 탐정"을 정식 비교로 배치하고, 슬라이드 6에서 "맞춤법 검사기 vs 편집장"을 배치합니다.

이로 인해 "CCTV vs 탐정" 비유가 슬라이드 4와 5에서 사실상 중복 사용됩니다. 슬라이드 4(2:00~2:30)의 발화문에서 이미 "기존 도구는 CCTV입니다... 바로 여기서 AI가 등장합니다"로 비유를 완결한 뒤, 슬라이드 5(2:30~3:15)에서 다시 동일 비유를 좌우 비교 형태로 반복합니다.

- 권고: 슬라이드 4의 CCTV 비유를 제거하거나 다른 도입부 표현으로 교체하고, 슬라이드 5에서 처음 등장하도록 정리하는 것을 권장합니다.

**슬라이드 수 차이**

기획서는 "예상 20-25장"으로 명시되어 있고, 실제 스크립트는 27장입니다. 기획서의 25장 목록에 없던 슬라이드가 추가된 부분은 다음과 같습니다.

- 슬라이드 4 (패턴 매칭의 한계 - 비유 도식): 기획서 목록에는 없는 독립 슬라이드로 분리됨
- 슬라이드 11 (모든 언어 지원): 기획서 13번 "지원 언어 목록 슬라이드"에 대응하나, 섹션 4에 배치됨
- 슬라이드 24 (Pre-commit hook): 기획서 목록에 없는 신규 슬라이드

이 차이 자체는 문제가 되지 않습니다. 기획서가 "예상"이라고 명시했고, 추가된 슬라이드들이 모두 내용의 깊이를 더해주기 때문입니다.

**기획서 주의사항 준수 확인**

| 주의사항 | 준수 여부 | 비고 |
|----------|:---------:|------|
| YAML 최소화 | 준수 | 슬라이드 16에서 핵심 3줄만 하이라이트, 나머지 "..." 축약 |
| 라이브 시연 없음 | 준수 | 모든 코드가 슬라이드 스크린샷/모의 화면으로 처리됨 |
| "대체가 아닌 보완" 프레이밍 | 준수 | 슬라이드 25, 26에서 명시적으로 강조 |
| PPT 배포 자료 정보 밀도 | 준수 | "전체 YAML 파일은 PPT 부록에" 발화문에서 안내 |
| 플랜 접근성 초반 안내 | 미준수 | 플랜 정보가 13:00에 등장. 기획서는 "초반에 안내" 권고 |

## 수정 권고 사항 (우선순위순)

1. **[Critical] 비용 수치 통일**: 스크립트(슬라이드 18)와 PPT 프롬프트(Slide 17)의 PR 규모별 파일 수 기준이 다름. 원문 자료를 기준으로 통일 필요.

2. **[High] 슬라이드 4 CCTV 비유 중복 해소**: 슬라이드 4에서 이미 CCTV 비유를 사용한 뒤 슬라이드 5에서 동일 비유를 반복. 슬라이드 4의 비유를 제거하고 브릿지 표현으로 교체 권고.

3. **[High] 발화문 분량 조정 (총 러닝타임 18분 초과 우려)**:
   - 슬라이드 10: 6가지 카테고리 중 핵심 3개만 발화, 나머지 화면 참조
   - 슬라이드 23: 시나리오를 1~2개로 축약
   - 슬라이드 25: 주의사항 1~2번을 합쳐서 발화

4. **[Medium] 플랜 접근성 초반 안내 누락**: 슬라이드 12에서 "이 기능은 Pro 플랜 이상에서 사용 가능합니다" 한 줄 삽입 권고.

5. **[Medium] PPT 프롬프트에 스크립트 전용 슬라이드 2개 추가**: 슬라이드 14(탐지 예시)와 슬라이드 24(Pre-commit hook)를 PPT 프롬프트에 추가.

6. **[Medium] PPT 프롬프트 주의사항에 "프롬프트 인젝션" 항목 추가**.

7. **[Low] 슬라이드 9 발화문 구어체 개선**: "방식 그대로를 AI가 수행하는" → "사람 보안 연구원이 코드를 리뷰하듯이, AI가 똑같이 수행하는"

8. **[Low] 섹션 8→9 전환 표현 추가**: "자, 마무리하기 전에 꼭 말씀드려야 할 것이 있습니다" 등 브릿지 추가.
