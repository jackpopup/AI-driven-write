## 슬라이드 27: Match Rate — AI 자가 품질 검사
- **유형**: 데이터/통계
- **텍스트**:
  - `90% 이상` → 자동 완료 ✅
  - `70~89%` → 선택권 제공 ⚡
  - `70% 미만` → 자동 재작업 🔄
- **비주얼**: 원형 게이지 3개 또는 하나의 미터가 채워지는 애니메이션. 구간별 색상(초록/노랑/빨강)
- **레이아웃**: 3개 게이지 가로 배치 또는 단계별 미터
- **애니메이션**: 게이지 바 채워지는 모션 → 각 구간 도달 시 레이블 pop-in
