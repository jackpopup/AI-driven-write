2. 문제 정의: AI 대분기 (The Great Bifurcation)

AI 도입 이후 조직은 두 부류로 갈라지고 있다.

  • Chatters (99%) — 챗봇에 질문하고 답변을 얻지만, 실행은 여전히 사람이 수동 처리. 생산성 향상 +20%.
  • Builders (1%) — AI 에이전트를 조합해 코드 작성, 배포까지 완결된 결과물을 생산. 생산성 향상 +1,000%.

이 격차의 근본 원인은 세 가지다.

  1. Skill Gap — 같은 조직 안에서 AI 활용 수준이 극단적으로 다르다.
  2. Psychological Barrier — "나만 뒤처지는 건 아닌가"라는 불안감과 학습 피로.
  3. Execution Gap — 단위 작업 속도는 올라갔지만 실제 서비스 배포·성과로 이어지지 못한다.

3. 세 개의 엔진: 격차를 좁히는 구조

팝업스튜디오는 위 세 원인 각각에 대응하는 전용 엔진을 제공한다.

bkit — Creation Engine (Skill Gap 해소)

Anthropic Claude Code 기반 AI 네이티브 개발 프레임워크. Context Engineering(AI가 정확한 결과를 내도록 맥락을 자동 설계하는 기술)으로 요구사항을 자연어로 기술하면 설계 문서 → 코드 구현 → 품질 검증 → 자동 수정까지 순환한다. PDCA(Plan-Design-Do-Check-Act) 방법론 기반, Zero Script QA(별도 테스트 코드 없이 실시간 품질 검증) 지원. 오픈소스로 공개되어 있다.

bkend — Infrastructure Engine (Execution Gap 해소)

AI 네이티브 BaaS(Backend as a Service, 백엔드 자동 구축 서비스). 자연어 설명만으로 DB, API, 배포가 자동 완료된다. 보안·도메인 설정 등 DevOps 엔지니어링이 자동화되어 별도 운영 인력이 필요 없다. 데이터 구조를 미리 설계할 필요 없이 바로 시작할 수 있는 스키마리스 구조를 채택했다. MCP(Model Context Protocol, AI 에이전트가 백엔드에 직접 접근하는 표준 프로토콜) 통합을 지원한다.

bkamp — Scaling Engine (Psychological Barrier 해소)

검증된 AI 워크플로우를 공유·확산하는 커뮤니티 플랫폼. Showcases(프로젝트 전시), Recipes(검증된 워크플로우), Riddles(실전 문제 협업) 3가지 콘텐츠를 8개국 언어로 제공한다. 고립된 학습 대신 집단 지성으로 불안감을 성장 동력으로 전환한다.

모방 불가능한 생태계 (The Uncopyable Ecosystem)

  • 상호 의존성 — bkit(Create) → bkend(Deploy) → bkamp(Scale) 순환 구조. 부분 모방으로는 동일 가치 제공 불가.
  • Lock-in — 사내 에이전트·워크플로우·문서 자산이 플랫폼 위에 축적되어 전환 비용이 높다.
  • Talent Upgrade — Chatters를 Builders로 전환시키는 것 자체가 핵심 가치.
