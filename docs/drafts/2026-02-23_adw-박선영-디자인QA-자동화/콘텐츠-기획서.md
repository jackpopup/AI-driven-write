1. 디자인 QA를 직접 하게 된 계기가 뭐였나요? 원래는 누가 했나요?
2. 31개 체크포인트는 어떻게 정했나요? 기준이 뭐였나요?
3. QA 자동화 커맨드를 처음 만들 때 얼마나 걸렸나요?
4. QA에서 버그를 찾고 직접 고친 경험 — 개발자 반응은 어땠나요?
5. "이건 자동화 안 돼요" 하는 QA 영역이 있나요? 어떤 건가요?
6. UX 감사를 코드 기반으로 하면 뭐가 달라지나요?
7. 다른 회사 디자이너가 이걸 따라하려면 첫 걸음이 뭘까요?
